# Prompt升级方案（数模C）

## 目标
把 AI 从“生成一篇像论文的文字”约束为“根据已批准模型和证据生成可审查的论证”。以下规则来自 2016–2019 可读样本的结构观察，并结合 2020–2023 A题可读样本对照；不是官方评分标准。

## 可直接加入写作 Prompt 的控制指令

```text
先读取题目分析、模型合同、结果文件和主张—证据表，再写任何正文；缺少证据时返回 MISSING_EVIDENCE，不得补写数字。
先按问题依赖和模型递进生成框架，再安排算法；禁止用算法名称作为章节主线。
每问必须生成“问题分析—假设/变量—模型—求解—结果—针对性检验—向下一问交接”闭环。
摘要按“研究对象—难点—模型—求解—核心结果—验证/边界”组织，每个定量结论标注证据文件。
每个主要公式后用一句话解释变量、目标、约束或边界条件的实际含义。
每个结果段落必须回答：得到什么、相对什么比较、为什么变化、对决策意味着什么。
每条关键假设必须填入“假设—模型组件—检验—适用边界”矩阵；矩阵空缺则不得写成模型已验证。
每张正式图表先登记主张、数据源、坐标、预期观察和正文位置；无主张的图不得进入终稿。
敏感性分析必须说明参数依据、扰动范围、指标变化、敏感方向、稳定区间和决策是否改变。
没有全局证明时，使用“给定算法/搜索范围下的最优候选”，不得使用“全局最优”。
模型评价必须同时写适用范围、限制和改进条件；禁止只写优点。
保留队伍自己的技术判断和具体语境，避免空泛的“显著、先进、合理、普适”。
```

## 审查 Prompt

```text
逐段检查：是否有证据、是否解释模型选择、是否说明变量含义、是否把结果写成因果、是否超出假设边界、是否把局部搜索写成全局最优。返回段落位置、严重级别、证据缺口和返工角色。
```
