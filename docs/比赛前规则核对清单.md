## 1. 参赛与纪律

- [ ] 三人均已阅读当届《参赛规则》
- [ ] 知道本赛区报名方式、参赛号和提交入口
- [ ] 竞赛期间不与队外任何人（含指导教师）讨论赛题
- [ ] 不浏览/发布/讨论赛题相关内容（含贴吧、QQ群、微信群、AI社区）
- [ ] 不使用未授权的外部数据/资料；引用他人成果按规范标注
- [ ] 赛题与附件不泄露到公开仓库或外部服务

---

## 2. 论文格式（提交前必查）

- [ ] 电子论文为 PDF（或当届认可的 Word），≤ 20MB
- [ ] 论文与支撑材料分成**两个独立文件**
- [ ] 第一页为**摘要页**
- [ ] 论文中**不放**承诺书、编号专用页
- [ ] **不放目录**
- [ ] 正文（不含摘要/附录）≤ 30 页（以当届规定为准）
- [ ] A4，四边页边距 ≥ 2.5cm（以当届规定为准）
- [ ] 摘要、正文、附录、文件元数据中**无**队员/学校/赛区身份信息
- [ ] 中文字体、公式、图表、页码正常（编译后人工翻 PDF 检查）

---

## 3. 支撑材料

- [ ] 使用一个 RAR/ZIP 压缩包，≤ 20MB
- [ ] 包含全部可运行源代码
- [ ] 包含自主查阅/收集的数据资料
- [ ] 包含必要的大型中间结果和图表
- [ ] 论文附录列出支撑材料文件清单
- [ ] 不含承诺书、编号页、凭据、API Key、身份信息
- [ ] 代码可运行且运行结果与论文一致

---

## 4. AI 使用（当届规则必读！）

- [ ] 明确队伍是否使用 AI（不能把"没确认"当"未使用"）
- [ ] 使用 AI → 论文中按当届要求加入 AI 工具使用声明/披露
- [ ] 使用 AI → 支撑材料含《AI工具使用详情》文件
- [ ] 详情含：工具名、版本/型号、用途与环节、主要提示方式、采纳/修改/核验情况
- [ ] 未使用 AI → 加入当届要求的"未使用声明"
- [ ] 核心建模与分析由队伍主导；所有 AI 输出经人工审查核实

> 数模 C 辅助：`python tools/c.py ai-report <项目目录>` 生成 AI 使用台账报告

---

## 5. 科学性（交卷前 30 分钟）

- [ ] 每个问题都有完整闭环：输入→假设→模型→求解→结果→检验
- [ ] 论文关键数字均来自实际运行结果（CSV/MAT/JSON）
- [ ] 公式与代码实现一致
- [ ] 图表与结果文件一致，每张图都有编号/标题/单位/正文引用
- [ ] 模型假设、目标函数、约束已由建模主+编程主双人复核
- [ ] 没有把局部最优写成全局最优；没有无证据的"显著/最优/普适"
- [ ] 摘要数字由两名队员从结果文件反向核对

---

## 6. 提交前最终动作（倒数 30 分钟）

- [ ] 冻结代码与数据版本，重新运行关键脚本确认可复现
- [ ] `cd 论文 && xelatex 论文.tex` 编译两遍，无致命错误
- [ ] 打开最终 PDF 检查：首页、摘要、目录(如有)、公式、图表、末页
- [ ] 按赛事要求重命名最终文件
- [ ] 支撑材料压缩包内文件与论文附录清单一致
- [ ] 队长最终确认提交
