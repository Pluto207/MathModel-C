# 2016–2019 传统高分范式综合报告

## 资料范围

本报告基于 `竞赛资料/2016–2019/**/优秀论文/*.pdf` 的 63 篇可抽取论文，以及其中 17 篇 A 题样本的摘要、问题分析、假设、建模、结果、检验、灵敏度和评价片段。2016–2019 被作为“AI广泛应用前的传统写作与建模样本”观察；这不是对单篇论文奖项或官方评分的重新认定。

## 主要范式

1. 摘要围绕研究对象、问题难点、模型、求解、核心结果和检验组织，而不是算法名清单。
2. 问题分析先解释现实过程、数据关系或约束，再说明为何引入某模型/算法。
3. 论文按问题机制递进：标定/基线 → 新变量或约束 → 优化/推广 → 异常情景或稳健性。
4. 假设不是孤立清单；优秀样本往往能把“忽略/保留机制”映射到方程、边界条件、目标函数或约束。
5. 结果分析常见有效链是“数值结果 → 对照 → 机制解释 → 决策含义/适用边界”。
6. 检验应与模型类型匹配：物理模型做量纲/边界/守恒/离散精度；优化做可行性/基线/重复或扰动；标定做精度与稳定性；调度做策略对照和故障情景。
7. 灵敏度分析的价值不在曲线数量，而在说明参数依据、扰动范围、敏感方向、稳定区间和决策是否改变。
8. 局限性写得具体反而增强可信度：说明被忽略机制、数据范围、算法边界和改进条件。

## 不应迁移的内容

具体公式、参数、阈值、算法和数值结果必须留在原题上下文中；“出现过某算法”不等于该算法适合新题；“优秀论文目录”不等于官方评分规则。

## 对数模C的直接改造

- 写作 Agent 由句式生成改为功能约束生成；
- 框架 Agent 先构建问题依赖图和模型递进，再安排章节和算法；
- 验证 Agent 建立假设—模型组件—检验—边界矩阵；
- 图表 Agent 先登记主张和预期观察，再生成图；
- 终审 Agent 对“全局最优、普适性、完全吻合、显著提升”等强结论要求证据门槛。

## 证据限制

部分 2020–2022 文件文本层较弱；2019 部分 PDF 也存在抽取质量差异。因此本报告的传统范式结论主要由 2016–2018 重点样本和 2016–2019 语料信号支持；后续跨时期对照需对可读样本逐篇复核。
