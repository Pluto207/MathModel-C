# 2018 RGV 动态调度案例卡片

- 来源：`竞赛资料/2018/A/优秀论文/2018A：基于多原则比较和蒙特卡洛模拟的 RGV 动态调度模型.pdf`
- 题型：离散事件过程 + 组合调度 + 多原则比较 + 随机故障扩展
- 核心链：作业流程刻画 → 时间/唯一性约束 → 目标函数 → 单工序基线 → 双工序分配 → 多原则比较 → 蒙特卡洛学习 → 故障情景。
- 表达亮点：先逐过程解释设备行为，再建立规划关系；把“就近/FIFO/HRRN”作为可解释策略比较，而非只报一个黑箱算法。
- 检验范式：不同规则对照 + 方案遍历 + 接近程度比较 + 故障情景效率下降分析。
- 可迁移：调度题先刻画事件和资源占用，再定义决策与目标；多算法比较必须共享指标和同一约束；故障扩展应明确新增随机变量。
- 风险提醒：局部搜索/模拟结果不能写成全局最优；“机器学习”若只是随机反馈策略，需准确说明其算法含义。
- 不可照搬：设备时间、布局和代码只属于原题。
