# 2017 CT 系统标定与图像重建案例卡片

- 来源：`竞赛资料/2017/A/优秀论文/2017国赛国家一等奖A题优秀论文1.pdf`
- 题型：几何标定 + 反问题 + 图像重建 + 稳定性分析
- 核心链：接收数据与穿透厚度关系 → 间距标定 → 旋转中心 → 射线方向 → 反投影重建 → 新模板改进
- 表达亮点：先从数据物理含义推导比例关系，再把未知系统参数转成目标函数；摘要逐问说明决策变量、误差目标和求解结果。
- 假设闭环：探测器精度、介质周围环境等假设用于简化衰减关系；几何关系和理论厚度提供验证依据。
- 检验范式：精度误差 + 多次/不同条件稳定性 + 新模板对比。
- 可迁移：先找数据的物理解释，再建立可计算目标；标定问题要区分精度和稳定性；改进方案必须说明改进机制。
- 不可照搬：Radon/反投影公式、模板几何和具体精度只属于原题。
