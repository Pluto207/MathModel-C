# 2023 A 定日镜场优化案例卡片

- 来源：`竞赛资料/2023/A/优秀论文/A092.pdf`、`A127.pdf`、`A165.pdf`、`A175.pdf`
- 题型：光学/几何机理 + 多因素效率计算 + 方案优化
- 共同模型链：太阳位置 → 坐标系/方向向量 → 镜面姿态 → 阴影/遮挡/截断/余弦等效率 → 年平均输出功率 → 数量/位置/尺寸优化。
- 结构观察：可读样本仍按“问题分析—假设—符号—模型建立与求解—结果/检验—评价”展开；优秀表达把光学过程拆成可计算的子过程，再汇总到总指标。
- 可迁移：复杂物理系统先分解过程损失/贡献，再定义总目标；坐标系、向量和中间效率应成为可复查的模型接口；不同方案比较必须保持同一指标口径。
- 检验重点：几何/物理边界、效率分量合理性、参数情景对照、优化方案可行性和敏感性。
- 不可照搬：定日镜坐标、太阳参数、具体效率公式和数值属于原题。
