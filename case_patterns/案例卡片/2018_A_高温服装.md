# 2018 高温作业服装设计案例卡片

- 来源：`竞赛资料/2018/A/优秀论文/2018A：基于非稳态导热的高温作业专用服装设计.pdf`
- 题型：物理过程建模 + 偏微分方程离散 + 参数反演 + 约束优化
- 核心链：多层传热抽象 → 一维热传导方程 → 初边值条件 → 有限差分/后向欧拉 → 参数估计 → 厚度优化 → 多变量扩展
- 表达亮点：问题分析把“忽略对流/辐射、分层、一维化”与方程结构连续连接；结果同时报告稳态温度、时间阈值和厚度方案。
- 假设闭环：材料平行、热传递方向、常系数和界面连续性分别对应空间模型、方程项、系数和界面条件。
- 检验范式：模拟与附件观测对照 + 反问题/边界重算 + 约束满足 + 厚度变化趋势。
- 可迁移：PDE 题必须同时交代物理方程、初边值条件、离散方法和稳定性；优化结果要回到题目中的安全、成本或舒适指标。
- 不可照搬：热参数、温度阈值、差分格式和厚度结果只属于原题。
