# 论文结构范式

## 章节生成原则

先根据题目过程、子问题依赖和模型递进生成框架，再把算法放进对应的求解环节。禁止以“遗传算法/神经网络/蒙特卡洛”等算法名称作为章节主线。

## 每问闭环

```text
问题分析 → 假设与变量 → 模型建立 → MATLAB求解 → 结果解释 → 针对性检验 → 小结/向下一问交接
```

每问结束时记录：继承给下一问的变量、参数、方程、结果和限制。

## 图表节奏

1. 系统/几何/流程图：回答“研究对象如何运行”；
2. 数据或过程图：回答“输入和中间量有什么结构”；
3. 结果图/表：回答“模型得到什么”；
4. 检验/敏感性图：回答“结果是否稳定、边界在哪里”。

图表不按数量硬凑；每张正式图必须绑定一个主张并在正文解释。

## 论文主线检查

- 摘要的每个核心结果在正文有落点；
- Q2/Q3 明确继承前问内容；
- 公式出现前说明建模理由，出现后解释含义；
- 结果之后紧跟比较或解释，而不是直接跳到下一节；
- 模型评价不引入正文没有验证的新结论。
