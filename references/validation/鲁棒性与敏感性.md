# 鲁棒性与敏感性分析

## 最低闭环

```text
选择对象 → 说明依据 → 设定扰动范围 → 重新计算 → 报告指标变化 → 解释敏感方向 → 判断决策是否改变 → 标出稳定区间/失效边界
```

## 按题型选择

- 物理/工程：参数、初值、边界、时间/空间步长、守恒量、材料或环境情景；
- 优化：初值、随机种子、算法参数、约束边界、基线和多情景可行性；
- 预测：时间切分、窗口、特征、误差指标、残差和区间覆盖；
- 评价：权重、标准化、指标方向和排序稳定性。

## 禁止

不能只画一条参数曲线；不能无依据选择扰动范围；不能把一次随机运行当作鲁棒性；不能用“趋势符合预期”替代指标；不能把敏感性分析写成因果证明。
