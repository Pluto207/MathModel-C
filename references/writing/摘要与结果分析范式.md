# 摘要与结果分析范式

## 摘要骨架

```text
本文研究【对象】中的【核心任务】。
针对问题一，依据【机制/数据关系】建立【模型】，通过【求解方法】得到【关键结果】。
在此基础上，针对问题二新增【变量/约束/情形】，采用【方法】得到【结果】，并通过【检验】说明【结论边界】。
其余问题依次写清【模型递进】、【关键决策】和【验证】。
```

摘要必须优先放真正回答题目要求的数字或结论，不堆放背景和算法名。

## 结果段落骨架

```text
在【参数/约束】下，模型得到【数值结果】。
与【基线/另一方案/观测】相比，【指标变化】。
该变化主要由【机制/变量/约束】导致。
因此，在【适用条件】下可采取【决策】，但当【边界】出现时需要重新校准。
```

## 递进式问题结构

```text
Q1：识别机制、建立基线或标定参数
Q2：继承 Q1，加入一个关键变量/约束
Q3：将前两问推广为设计、优化或多情景分析
Q4：检验稳健性、处理异常情形或提出推广方案
```

不要求每道题都服从此顺序；实际题目依赖优先。
