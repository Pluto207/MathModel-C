# 高分表达控制（基于 2016–2019 样本观察）

## 生成指令

- 摘要按“研究对象与目标 → 关键困难 → 模型思路 → 求解方法 → 核心结果 → 验证/边界”组织；不要只罗列算法名称。
- 每个问题的结果分析必须覆盖“数值结果、对照对象、变化原因、实际含义”；缺一项就标记为待补证据。
- 使用“针对……，首先……；在此基础上……；进一步……；最后……”表达递进，但每个连接词后必须承载真实的模型或证据变化。
- 每个主要公式后解释新变量、目标函数、约束或边界条件的题目含义；不要连续堆公式而不解释。
- 将“结果表明”后的句子写成可检验判断，并紧接证据位置；禁止用空泛形容词替代指标。
- 模型评价同时写适用范围、主要限制和改进方向；限制必须对应被忽略的机制、数据范围或算法边界。
- 结论中区分“计算得到”“在给定参数下观察到”“在当前搜索范围内获得”；禁止无证据扩大外推范围。

## 过渡句功能库

| 功能 | 推荐结构 |
|---|---|
| 由题意入模 | 题目中的……决定了……，因此将……作为……并建立…… |
| 由物理入方程 | 在……假设下，……项可忽略/保留，系统关系可写为…… |
| 由前问入后问 | 前一问得到的……为本问提供……，本问仅新增…… |
| 由模型入算法 | 由于目标函数具有……、变量满足……，选用……求解 |
| 由结果入解释 | 由表/图可见……；这意味着……，原因在于…… |
| 由检验入结论 | 在……扰动/替代推导下，指标变化为……，说明…… |
| 由限制入推广 | 当前模型未考虑……，因此结论适用于……；若引入……可进一步…… |

## 禁止表达

- “采用先进算法，结果很好”；
- “模型具有很强的普适性”但没有迁移条件；
- “实验结果完全吻合”但没有误差或比较指标；
- “最优解/全局最优”但没有对应证明或充分搜索证据；
- 只写“由图可知”而不写图中具体变化和决策含义。

本文件是可迁移写作规则，不是对官方评分标准的复述，也不复制任何单篇论文原句。
