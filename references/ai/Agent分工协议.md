# Agent 分工协议

## 推荐角色

| Agent | 任务 | 只读/写入边界 |
|---|---|---|
| 题目分析 Agent | 提取问题、变量、约束、数据风险、依赖图 | 只读输入，输出分析草稿 |
| 机理建模 Agent | 推导关系、量纲、边界、基线和反例 | 不裁决最终假设 |
| MATLAB Agent | 函数框架、维度检查、求解和测试 | 只能写指定项目目录 |
| 算法对照 Agent | 比较模型和算法的适用条件、复杂度、失败风险 | 不以算法名称替代理由 |
| 结果审查 Agent | 检查 NaN/Inf、范围、约束、基线差异、稳定性 | 只读结果，不改结果 |
| 论文审查 Agent | 检查公式—代码—结果—图表—文字一致性 | 只提问题，不直接改权威稿 |
| 反方审稿 Agent | 构造反例、质疑假设、检查过度结论 | 输出风险清单 |

## 调度原则

Agent 可以并行做互不依赖的只读分析；同一权威代码、结果或论文不得由多个 Agent 同时写入。模型合同冻结前不得并行大规模实验。每个 Agent 返回：范围、输入、结论、证据、未知项、建议。

## 人类复核门

Agent 的 PASS 只是辅助意见，不等于队伍通过。涉及科学结论的内容必须由队员标记 `REVIEWED` 或 `APPROVED` 后才能下游使用。
