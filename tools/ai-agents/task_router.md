# Agent 任务路由

## 选择规则

- 题目分析：只读 `题目/` 和附件，输出问题地图。
- 机理建模：只读题目分析和模型合同草稿，输出方程、量纲、假设风险。
- MATLAB：只在指定 `求解/问题X/` 写入；必须先基线和最小切片。
- 结果审查：只读代码、结果、图表，不能改结果。
- 论文审查：只读论文和证据表，不能改权威稿。
- 反方审稿：只读全项目，输出过度结论、反例和规则风险。

## 调度命令示例

```bash
python 数模C/tools/ai-agents/route_task.py 2026国赛-A题 \
  --agent matlab --stage q1_minimum \
  --task '实现Q1基线并从项目根目录运行' \
  --read '题目分析报告.md' --read '模型合同-模板.md' \
  --write '求解/问题1' --forbid '论文' --forbid '结果手工修改'
```

该工具只生成有边界的交接任务 JSON，不自动启动 Agent；是否调用 Agent 由队伍按比赛规则和实际需要决定。
