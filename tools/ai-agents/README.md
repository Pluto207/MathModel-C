# Agent 调度入口

## 推荐调度顺序

1. 题目分析 Agent：只读题目和附件，输出问题地图；
2. 机理建模 Agent：只读题目分析，输出候选方程、假设、量纲与反例；
3. MATLAB Agent：读取已批准模型合同，只写指定问题目录，先跑基线和最小切片；
4. 结果审查 Agent：只读结果和代码，检查数量级、约束、单位、稳定性；
5. 论文审查 Agent：只读论文和证据表，检查主张—公式—代码—结果—图表链；
6. 反方 Agent：只读全项目，寻找过度结论、数据泄漏和不可复现点。

## 互斥写入

同一权威代码、结果或论文不得由多个 Agent 同时写入。每个 Agent 任务必须写明允许读取、允许写入、禁止事项、输出路径和返回格式。

## 统一返回

`范围 / 输入版本 / 实际动作 / 命令与退出状态 / 输出 / 未知项 / P0-P2风险 / 需要队员确认`。
